# 📊 Decathlon Sales Analysis | Excel Data Analytics Project

An end-to-end **Data Analytics project using Microsoft Excel** to analyze **30,000 Decathlon sales transactions** and uncover insights into sales performance, profitability, customer behavior, products, channels, locations, promotions, and returns.

The project demonstrates how raw transactional data can be transformed into a structured analytical model and an interactive dashboard using **Power Query, Power Pivot, DAX, Pivot Tables, and Excel visualizations**.

---

## 🎯 Project Objective

The main objective of this project is to answer important business questions such as:

* Which product categories generate the highest revenue?
* Which sales channels perform best?
* Which states contribute the most to overall sales?
* How do returning customers contribute to revenue?
* What is the overall profitability?
* How many orders are returned?
* How do promotions and customer segments affect sales?
* Which business areas require further attention?
